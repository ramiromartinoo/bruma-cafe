# Bruma Café

Landing para una cafetería de especialidad al paso en Playa Grande, Mar del Plata: café, dulce, salado y almuerzos para llevar.

- **GitHub Pages:** https://ramiromartinoo.github.io/bruma-cafe/
- **Netlify:** https://bruma-cafe-demo.netlify.app

## Qué incluye

- Carta por categorías
- Pedidos por WhatsApp
- Sección de delivery y suscripción de un café por día
- Diseño responsive, pensado primero para celular

## Stack

Un solo `index.html` con HTML, CSS y JavaScript sin dependencias. Tipografías de Google Fonts.

## Sobre el historial de commits

El sitio se desarrolló localmente y se publicó primero en Netlify con deploy manual (subiendo la carpeta). Este repositorio se creó después para tenerlo en GitHub, por eso el historial arranca con un único commit que contiene el sitio terminado. Los cambios nuevos se registran acá como commits normales.
